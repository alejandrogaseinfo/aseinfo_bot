# Caso Historico De Oracle En Facturacion

## Incidente

En un caso historico de facturacion se reporto un error Oracle despues de un ajuste de dependencias.

## Hallazgo

El problema estaba relacionado con una diferencia entre la version de la base y los parametros requeridos por el modulo actualizado.

## Referencia

El caso no aplica automaticamente a otros modulos, pero puede servir como antecedente cuando aparezcan errores de base de datos tras una actualizacion.

## Siguiente Paso Sugerido

Comparar version instalada, scripts ejecutados y dependencias antes de asumir que se trata del mismo origen.
