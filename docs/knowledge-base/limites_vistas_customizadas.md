# Limites Tecnicos De Vistas Customizadas

## Alcance

Las vistas customizadas permiten reorganizar campos, ocultar columnas y ajustar ciertos comportamientos visuales ya previstos por la aplicacion.

## Limites

No deben usarse para introducir logica de negocio nueva, consultas complejas no soportadas por la pantalla base ni integraciones adicionales.

## Escalamiento

Si la necesidad implica cambios estructurales, nuevas reglas de negocio o comportamiento no previsto por la configuracion, el caso debe escalarse al equipo de desarrollo.
