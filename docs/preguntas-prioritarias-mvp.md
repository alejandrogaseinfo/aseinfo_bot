# Fase 0 - Preguntas Prioritarias Del MVP

## Lista Inicial

Estas son las preguntas que el MVP debe poder resolver o enrutar correctamente.

1. Este error aparecio despues de instalar el hotfix o actualizar el paquete, ya esta documentado o resuelto?
2. Este paso de instalacion o esta advertencia ya estaba indicado en el readme o en el setup?
3. Esta personalizacion o vista customizada se puede hacer sin desarrollo?
4. Cual es el limite tecnico de esta funcionalidad antes de pasar el caso al equipo de desarrollo?
5. Este error de Oracle o de base de datos ya habia ocurrido antes?
6. Existe un caso parecido en otro modulo o pantalla que sirva como referencia?
7. Este problema ya fue reportado y sigue en progreso?
8. Hay una correccion, workaround o recomendacion documentada para este comportamiento?
9. Este detalle tecnico del hotfix esta documentado en algun readme, ticket o antecedente historico?
10. No hay evidencia suficiente y debo escalar este caso a desarrollo?

## Criterio De Priorizacion

Estas preguntas fueron priorizadas porque:

- generan interrupciones frecuentes al equipo,
- suelen tener evidencia parcial en documentos o tickets,
- pueden responderse con un formato consistente,
- y aportan valor aunque el bot aun no automatice procesos.

## Criterio De Aceptacion

La Fase 0 se considera cerrada si estas preguntas representan el conjunto inicial contra el que se evaluara el MVP en desarrollo y en piloto.
